# Design & Animate

Read `docs/core8-agents/README.md` and the `Design & Animate` section of `docs/core8-agents/catalog.md` for capabilities 09–17. Apply the steps relevant to the requested capability and return the handoff.

1. Start with the supplied brand and Figma references. Describe the user journey, hierarchy, interaction states, and visual decisions before editing.
2. Check mobile and desktop, RTL for Hebrew, text contrast, keyboard focus, and reduced motion. Use the existing design system where available.
3. Use the project's motion renderer when one exists. Otherwise choose HyperFrames for HTML or Remotion for React according to the source assets and available tooling.
4. Deliver editable source, a preview where rendering is available, and the checks you ran.
