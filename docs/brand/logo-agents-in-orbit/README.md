# Core8-AI "Agents in orbit" logo — proposal

**Status: proposed; Lev chose this direction on 2026-11-19 over the single-orbit
and the radial "eight agents" versions. Not final brand artwork and not
cleared.** No trademark or similarity search has been done.

Eight agents on a tilted orbit around one core, drawn with depth: far agents are
smaller and fainter, near agents are larger and pass in front of the core.

Known trade-offs, recorded so they are not rediscovered later:
- At 16 px the full symbol reads as scattered dots. Use `favicon.svg`, which has
  larger, stronger agents, for anything that small.
- The symbol is asymmetric; it is optically centred in its box, but check
  alignment when placing it inside circles.

Drawn from scratch as SVG. The wordmark is Inter ExtraBold (SIL Open Font
License) converted to outlines, so the files need no font installed.

| File | Use |
