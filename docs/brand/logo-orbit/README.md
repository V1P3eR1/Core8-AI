# Core8-AI "Orbit" logo — proposal

**Status: proposed, chosen by Lev as a direction on 2026-11-19. Not final brand
artwork and not cleared.** No trademark or similarity search has been done. A
core with a tilted orbit ring is a common motif among technology and space
brands; check before adopting it.

Drawn from scratch as SVG. The wordmark is Inter ExtraBold (SIL Open Font
License) converted to outlines, so the files need no font installed.

| File | Use |
|---|---|
| `core8-logo-horizontal-on-dark.svg` / `-on-light.svg` | Primary lockup |
| `core8-logo-stacked-on-dark.svg` / `-on-light.svg` | Square spaces |
| `core8-mark-on-dark.svg` / `-on-light.svg` | Symbol only |
| `core8-mark-white.svg` / `core8-mark-ink.svg` | One colour |
| `favicon.svg` | Browser tab / app icon (simplified, no satellite) |
| `preview.png` | Overview sheet |

Colours: cyan `#00d4ff`, violet `#7c5cff`, ink `#0b0d1f`, background `#05060f`.
