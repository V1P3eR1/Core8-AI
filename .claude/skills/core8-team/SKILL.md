# Route a Core8-AI task

1. Read `docs/core8-agents/README.md` for scope and handoffs.
2. Read the relevant section in `docs/core8-agents/catalog.md`. Match an explicit number or tool name to its department. For an entire job, start with the output and select only the capabilities that advance it.
3. Carry the brief, inputs, output, and permitted actions into the matching department skill or native agent. Collect a verified handoff.
