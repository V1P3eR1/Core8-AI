# Make the Posts

Read `docs/core8-agents/README.md` and the `Make the Posts` section of `docs/core8-agents/catalog.md` for capabilities 26–33. Apply the steps relevant to the requested capability and return the handoff.

1. Start with the brief, brand, channel, format, and approved source assets. Ask for missing facts only when a faithful draft depends on them.
2. Create a script, visual direction, and editable asset source. Use the selected provider when enabled, and label a prompt or storyboard as such when a finished asset cannot be rendered.
3. Review factual copy, Hebrew rendering, subtitles, safe margins, and platform dimensions. Keep source assets and outputs linked in the manifest.
4. Give Grow the reviewable draft, local file paths, and asset references for the selected channel.
